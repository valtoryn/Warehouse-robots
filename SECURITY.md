# Security and Safety Policy

## Project maturity

Valtoryn Warehouse Robotics is in an early research and architecture phase. The repository currently contains
documentation and a documentation-checking script only; there is no deployable software. No version is supported for
production use.

## Reporting a security vulnerability

Please do not open a public issue for a suspected vulnerability.

- Use GitHub's private vulnerability reporting for this repository (the "Report a vulnerability" button under the
  repository's Security tab), if it is enabled.
- If it is not available, contact the repository owner through their GitHub profile
  (https://github.com/bhogesararam23) and ask for a private channel. Do not include exploit details in a public
  message.

A dedicated security contact address has not been established yet. Reports are handled on a best-effort basis by the
owner; no response-time commitment is made at this stage.

## Safety disclaimer (important)

Warehouse robots can injure people and damage property. Nothing in this repository is certified, safety-rated or
validated for operation near people. In particular:

- Passing simulation tests is not physical safety certification.
- Documentation of a safety concept is not an implemented or validated safety function.
- Any real deployment requires a documented risk assessment, safety-rated hardware where applicable, physical
  validation, and conformity assessment by qualified parties under the regulations that apply in the deployment
  jurisdiction.
